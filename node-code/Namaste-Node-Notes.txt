What is global?
global is NodeJS-specific and serves as the top-level object containing built-in functions like console and setTimeout.
It does not exist in browsers, where attempting to access it throws a ReferenceError.​
This environment-specific nature limits its use to server-side code.
global is only specific to NodeJS as will give different result based on different enviroment.

What is globalThis?
So we already saw the problem with global and to solve this globalThis was introduced in ES2020. globalThis is a standardized, 
cross-platform way to access the global object that works everywhere - browsers (window), Node.js (global), and Web Workers (self).

globalThis solves this by providing one consistent reference across all environments. In global scope, 
this equals globalThis, making it memorable.​

javascript
// Inside Node.js
console.log(globalThis === global); // true

// Inside a web browser
console.log(globalThis === window); // true
